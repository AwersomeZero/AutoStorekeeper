## Описание
Данный скрипт создан "на коленке" для перевода MaterialList из мода Litematica в таблицу Excel. Он предназначен для организаторов больших временных складов под мегапроекты масштаба Пепелэнда и позволяет быстро определить точное количество сундуков/шалкеров и табличек. Помимо большего удобства работы с листом благодаря табличному процессору и ускорению стройки склада для крупного проекта (спавн/хаб и т.п.), к списку добавляются столбцы "Стаки" (кол-во стаков с запасом), "Даблчесты" (число двойных сундуков с запасом) и "Шалкербоксы". Также в скрипте реализована особая сортировка блоков - она основана на принципах логистики и оптимизации пути, сокращая время на поиск ячейки с искомым блоком. Гайдлайны к созданию склада и методическое обоснование данной сортировки описано ниже. Краткий обзор метода сортировки:
 * В начале списка находятся все блоки, занимающие более одного шалкербокса. Они занимают первый отдел склада.
 * В середине списка находятся блоки объёмом от 1 до 27 стаков. Они занимают второй отдел склада
 * Оставшуюся часть списка занимают более мелкие по количеству ресурсы. Они занимают третий отдел склада.
 * Внутри отделов ресурсы отсортированы по рубрикам, категориям и подкатегориям из творческого инвентаря. Таким образом, все блоки из одного материала будут находиться рядом друг с другом, образуя подкатегорию (дубовые доски, люки, двери и т.п.), все подкатегории будут образовывать уже более крупную категорию (деревянные блоки, каменные блоки, керамика и т.п.), а все категории образуют рубрику из инвентаря креатива (строительные блоки, природные блоки, функциональные блоки и др.)

## Работа с программой на версии 26.2
1. Сохраните из схематики materiallist: Размещённые голограммы -> Настроить -> Список материалов
-> (с зажатым Alt) Экспорт. JSON файл запишется в minecraft/config/litematica. 
2. Откройте web интерфейс программы по ссылке:
3. Перенесите данный materiallist в указанную область, либо выберите файл по кнопке.
4. Готово! Результат можно сохранить себе на ПК, либо посмотреть прямо в браузере
**Если произойдёт ошибка и какой-либо блок/предмет не будет найден в базе данных, информация появится в текстовом окне логов. Сообщите об этом создателю.**

## Гайдлайн по постройке склада от сотрудников Фонда ППЛ (РЕДАКТИРУЕТСЯ)
Если вы хотите не просто поставить сундуки на скорую руку, а выжать максимум удобства и эффективности из постройки и использования склада - данный раздел для вас.
<img width="1920" height="986" alt="2025-11-10_19 38 34" src="https://github.com/user-attachments/assets/0b74c48d-7aa0-4de3-9480-9507f77b8e2a" />


В первую очередь - расположение сундуков. Если вы хоть раз строили крупный проект (или внимательно смотрели стрим PWGood-а и засекали время), то могли заметить, что примерно 30 минут времени уходит на то, чтобы найти, взять и затем сложить все ресурсы. Это очень неэффективная и геморная система, так как блоки расположены по списку из схемы. Самым удобным вариантом является комбинированная сортировка блоков по трём разделам - больше 1 ШБ, 1-27 стаков, меньше 1 стака.
<img width="1920" height="986" alt="2025-11-10_19 35 12" src="https://github.com/user-attachments/assets/714ab77e-5e49-42d0-aebc-29bd474a0872" />


Первая группа отсортирована по количеству блоков. Здесь без изменения, так как чаще всего таких блоков немного.
<img width="1920" height="986" alt="2025-11-10_19 35 19" src="https://github.com/user-attachments/assets/facedff2-2784-43e0-904e-0ef1ad843d0b" />


Вторая и третья группа отсортированы строго по категориям (дерево, камень, цветные блоки и т.п.) и подкатегориям (дубовые, еловые, берёзовые блоки и т.п.)
<img width="1920" height="986" alt="2025-11-10_19 35 22" src="https://github.com/user-attachments/assets/5e8d3a3e-3b91-47fb-bbeb-fe622e00a4dd" />

Далее - постройка площадки и установка сундуков. Если блоков совсем немного, то вы можете использовать бочки как более дешёвую альтернативу сундукам. Обязательно помечайте сундуки/бочки табличками с указанием названия блока, другие игроки смогут сразу же пополнять ресурсы, а также искать хранилище с помощью команды /sigsearch (если установлен мод Pochatok). Рекомендуется размещать сундуки в 4 ряда для экономии места, в противном случае игрокам придётся много бегать по складу, чтобы взять нужные блоки. 


Финальным штрихом являются визуальные пометки - это примеры блоков над сундуками. С помощью них можно "на глаз", не используя таблички, найти нужный блок. Чтобы размещать их было быстро и удобно, постройте сзади сплошную стену из стекла (или другой нейтральный полный блок) с отступом на 1 блок вверх, чтобы не мешать сундукам. Уже опираясь на эту стену разместите примеры блоков. Если блок слишком большой (картина/дверь) или нестандартной формы (повторитель) - поставьте их в рамку. Убедитесь, что с земли видны все блоки! Для удобства установки примеров блоков используйте подмостки.
